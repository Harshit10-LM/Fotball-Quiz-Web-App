# ⚽ Football Quiz App

A professional full-stack football quiz web application inspired by the premium experience of UEFA fantasy-style platforms. Built with **HTML, CSS, JavaScript, and Flask**, this project delivers an engaging quiz experience with leaderboard tracking, admin management, and responsive modern UI.

---

# 🚀 Features Included

## 🎨 Frontend Features

### 🏠 Home Page

* Modern football-themed landing page
* UEFA-inspired premium design
* Responsive navigation bar
* Hero section with call-to-action
* Feature highlights section
* Smooth animations and hover effects

### 🧠 Quiz System

* Start quiz with player name
* Multiple-choice football questions
* Categories such as:

  * UEFA Champions League
  * FIFA World Cup
  * Premier League
  * Football Legends
* Timer for each question
* Progress bar
* Instant answer selection feedback
* Score calculation
* Final result screen
* Play again option

### 🏆 Leaderboard

* Live leaderboard with rankings
* Top players highlighted
* Sorted by highest score
* Search player names
* Professional card/table UI

### 🛠️ Admin Panel

* Add new quiz questions
* Manage football question database
* Input validation
* Success/error notifications
* Easy question submission form

### 📱 Responsive Design

* Mobile-friendly layout
* Tablet support
* Desktop optimized
* Smooth navigation on all devices

---

# ⚙️ Backend Features

### 🔌 REST APIs

* `GET /questions` → Fetch all quiz questions
* `POST /questions` → Add new question
* `GET /leaderboard` → Fetch leaderboard scores
* `POST /leaderboard` → Save player score

### ✅ Data Validation

* Prevent empty inputs
* Validate question structure
* Ensure correct answer matches options

### 🗂️ In-Memory Database

* Uses Python lists/dictionaries
* Fast and simple data storage
* Preloaded football questions

### 🌐 Deployment Ready

* Separate frontend and backend folders
* Ready for GitHub repositories
* Easy deployment on:

  * Netlify / Vercel (Frontend)
  * Render / Railway (Backend)
